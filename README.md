# AVCore（AI Video Core）

> 面向开发者的**纯后端** AI 数字人视频生成框架。**生成一个人物角色模型，持续训练并演进，然后用它产出成片。**

## 这是什么

AVCore 是一个可集成到任意产品中的后端框架。它以 **人物角色模型（PersonaModel）** 为顶层抽象，把"形象 + 声音 + 人设 + 可选知识"打包成一个可被持续训练、可被多版本管理、可被复用的**活模型**。

```
任意设定（专家 / 虚拟主播 / 真实人物复刻 / 虚拟员工 ...）
                │
                ▼
 ┌──────────────────────┐    ┌─────────────────────────┐
 │  人物角色模型生成     │ →  │   PersonaModel v1       │
 │  （一次性创建）       │    │  形象 + 声音 + 人设 + 可选知识 │
 └──────────────────────┘    └────────────┬────────────┘
                                          │
              持续追加样本 / 反馈回灌         │
                                          ▼
 ┌──────────────────────┐    ┌─────────────────────────┐
 │  人物角色模型完善演进 │ →  │   PersonaModel v2 / v3  │
 │  （持续训练）         │    │  含 Identity Anchor 一致性兜底 │
 └──────────────────────┘    └────────────┬────────────┘
                                          │
                                          ▼
                               ┌────────────────────┐
                               │   视频生成          │ → final.mp4
                               │ （锁定 version 出片）│
                               └────────────────────┘
```

> **关键点**：模型不是造一次定型，而是被持续训练；并且跨版本身份一致，不漂移。

---

## 核心特性

- **以 PersonaModel 为中心**：形象 / 声音 / 人设 / 知识（可选）打包为可装可拆的能力维度
- **可演进**：通过追加样本、微调产出新版本；每个版本是不可变快照
- **身份一致**：跨版本用 Identity Anchor 评估与兜底漂移
- **可插拔模型**：每个能力点抽象为 Provider，可替换
- **纯后端**：REST / gRPC / Webhook / WebSocket，无任何前端绑定
- **可编排**：训练与渲染统一 DAG，节点级重试 / 断点续跑 / 观测
- **可资产化**：PersonaModel 与其版本可独立管理 / 复用 / 灰度

---

## 谁会用到

- **技术专家 / 行业讲师**（带知识语料）
- **虚拟品牌代言人 / 虚拟主播 / Vlogger**（强形象 + 人设，不一定带知识）
- **真实人物数字孪生**（本人授权的形象 / 声音复刻）
- **数字员工 / 虚拟助手**（知识型或不带知识型都可以）
- ……任何"具备视觉 + 听觉 + 人设"的稳定身份

> 一个 PersonaModel 可以**先塑形，再灌知识**；也可以**完全不灌知识**。
