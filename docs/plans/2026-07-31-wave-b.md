# Wave B · Avatar / Voice / Video Provider + DAG + Render

> 接 Wave A。本波把所有 "Phase 1 ⬜" 里的最大头落地：3 个真 Provider + DAG 真调度 + render 真出片。

**Goal:** `avc provider test {avatar,voice,video}.<name>` 真探针；`avc render run` 真走 DAG 五节点输出 artifacts BLOB；persona 完成后端到端可跑：`init → provider set → persona onboard → render run`。

**Architecture:**

- `real.rs` 内追加三个真 Provider impl（仿 LLM/Embed 模板）：
  - `OpenAiCompatAvatarProvider`：调 `/images/generations` → base64 PNG
  - `OpenAiCompatVoiceProvider`：调 `/audio/speech` → WAV；`clone`/`finetune` 为 token-only stub（无 OpenAI 标准 endpoint）
  - `CliVideoProvider`：抽象"提交-轮询-拿 mp4"三阶段；用 token 调用 provider cli 工具（如 kling-cli / doubao-cli）—— Phase 1 仅封装 mock path，正式接 vendor 在 Phase 2
- 工厂 `make_avatar` / `make_voice` / `make_video` 同 make_llm/make_embed
- `provider test <dim>.<name>` 增 avatar/voice/video 三分支
- `pipeline.rs`：把 `execute()` 升级成真调度——支持 `script_gen → tts + img_gen → i2v → compose` 串并行
- `job_steps` 表落库节点结果
- `render.rs`：`create_job` 后调用 `pipeline.execute()`，最后 status=succeeded + artifacts BLOB 落
- Phase 1 DAG 默认用 Mock（节省 token，可重复）；Wave C 加 LLM/Embed 真 Provider 节点路径

**Tech Stack:** 既有依赖零新增。

**非范围：**

- 不真接 vendor CLI（kling-cli 等）—— 仅保留接口 + 调用 hook
- 不写真/音/视频 BLOB 真格式（仍是占位字节；Phase 2 接 vendor）
- 不实现 finetune publish 走真 drift（仍保持手 mock，由 `drift eval --embed` 补充）

### Task B2: Pipeline DAG 真调度 + job_steps 落库

**Files:** `src/svc/pipeline.rs`, `src/svc/render.rs`

**Step 1:** pipeline 重构：保留 `DagSpec`/`NodeSpec`，加 `run(db, job_id, spec) -> AvcResult<()>` 函数：
- 读 spec 节点按 DAG 拓扑排序
- 顺序执行每个节点：写 `job_steps` (pending → running → succeeded/failed)
- 失败 → job 状态 = failed + 整体 rollback script（暂不）
- 节点输出落 `outputs_json`

**Step 2:** 五节点内置 spec：`render_publishment_spec()`:
- 0: script_gen (LLM chat) [Mock]
- 1: tts (OpenAI /audio/speech) [Mock 占位]
- 2: img_gen (OpenAI /images/generations) [Mock 占位]
- 3: i2v (视频 model) [Mock 占位]

每个节点调用 Phase 1 Mock Provider（mock.rs 已存在），生成对应 BLOB 落 artifacts 表。

**Step 3:** 写 unit tests：`pipeline_runs_spec_topological_order`, `pipeline_records_steps_on_failure`。

**Step 4:** 跑测试通过。
