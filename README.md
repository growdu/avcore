# AVCore（AI Video Core）

> 面向开发者的**纯后端** AI 视频生成核心框架。造一个数字人、养成一个专家、一键产出成片。

[![docs](https://img.shields.io/badge/docs-EN-blue)](./docs/README.md)

## 这是什么

AVCore 是一个可集成到任意产品中的后端框架，提供完整的 AI 视频生成能力链路：

```
角色设定 + 声音样本
        │
        ▼
 ┌──────────────────┐    ┌──────────────────┐
 │  人物形象建模    │ →  │  形象 + 声音资产 │
 └──────────────────┘    └────────┬─────────┘
                                  │
                                  ▼
 ┌──────────────────┐    ┌──────────────────┐
 │  角色养成        │ →  │      Persona     │
 │  专家养成        │ →  │  Expert + RAG    │
 └──────────────────┘    └────────┬─────────┘
                                  │
                                  ▼
                        ┌──────────────────┐
                        │   视频生成       │  → final.mp4
                        │ （工作流编排）   │
                        └──────────────────┘
```

---

## 核心特性

- **纯后端**：REST / gRPC / Webhook / WebSocket，无任何前端绑定
- **可插拔模型**：每个能力（形象 / 声音 / LLM / 视频）抽象为 Provider，可替换
- **可编排**：DAG 描述全流程，节点级重试与断点续跑
- **可资产化**：角色 / 形象 / 声音 / 知识 / 模板均可独立管理并复用
- **可观测**：全链路 Trace / Metric / Log
